# Design System
- **Theme**: Dark Mode Only (Terminal aesthetic).
- **Backgrounds**: Main `bg-slate-950`, Panel `bg-slate-900`.
- **Text**: `text-slate-100` for primary, `text-slate-400` for secondary.
- **Accents**: `emerald-500` for success/safe states, `cyan-400` for interactive elements, `rose-500` for high-risk warnings (GPS data found).
- **Icons**: Lucide Icons (imported as ES modules).
- **Typography**: Inter or system sans-serif for UI, JetBrains Mono for metadata values.
